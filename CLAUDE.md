# NixOS Workstation Dotfiles

## What this repo is

Declarative NixOS configuration for a personal workstation. Everything is reproducible — rebuilding from scratch should produce the same system.

**Stack**: Niri (Wayland WM) · Noctalia (desktop shell — panels, dock, notifications) · WezTerm · Neovim (LazyVim) · Firefox

> **Noctalia** ([docs](https://docs.noctalia.dev/v4/)) is a QML/Quickshell desktop shell, not a CLI shell. It provides the visual layer on top of Niri (status bar, launcher, notifications, widgets). Requires `nixpkgs-unstable` and its own flake input.

---

## Architecture

### Nix Flakes
The repo is a [Nix Flake](https://nixos.wiki/wiki/Flakes). `flake.nix` is the single entry point — it declares all external inputs (nixpkgs, home-manager, etc.) and produces NixOS system configs as outputs. `flake.lock` pins every input to an exact commit; never delete it.

### NixOS modules (system config)
Lives under `hosts/<hostname>/`. Controls kernel, hardware, networking, system services, and users. Requires `sudo nixos-rebuild switch`.

### Home Manager (user config)
Lives under `home/`. Controls everything user-facing: shell, apps, dotfiles, themes. Home Manager is integrated as a NixOS module so a single `nixos-rebuild switch` applies both.

## Directory layout

```
flake.nix                  # inputs + outputs
flake.lock                 # pinned inputs — commit after updates
hosts/
  nixos/
    default.nix            # system config (hardware, users, services)
    hardware-configuration.nix  # generated by NixOS installer — do not hand-edit
home/
  default.nix              # Home Manager root, imports all modules
  niri.nix                 # Niri compositor config + spawn-at-startup for Noctalia
  noctalia.nix             # Noctalia desktop shell (panels, dock, notifications)
  shells/
    default.nix            # imports all three shells, sets Fish as login shell
    fish.nix               # Fish (default login shell)
    zsh.nix                # Zsh (available, not default)
    nushell.nix            # Nushell (available, not default)
  wezterm.nix              # WezTerm terminal
  nvim.nix                 # Neovim / LazyVim
  firefox.nix              # Firefox with extensions
```

## Common commands

```bash
# Apply system + home config (run from repo root)
sudo nixos-rebuild switch --flake .#nixos

# Dry-run to check for errors without applying
sudo nixos-rebuild dry-activate --flake .#nixos

# Roll back to previous generation if something breaks
sudo nixos-rebuild switch --rollback

# Update all flake inputs (do this intentionally, then commit flake.lock)
nix flake update

# Update a single input
nix flake update nixpkgs

# Show what changed between generations
nvd diff /run/current-system result

# Search for a package
nix search nixpkgs <name>

# Open a temporary shell with a package (for testing)
nix shell nixpkgs#<name>

# Garbage-collect old generations (free disk space)
sudo nix-collect-garbage -d
```

## NixOS concepts (quick reference)

| Term | What it means |
|------|---------------|
| **Derivation** | A build recipe: inputs → a path in `/nix/store` |
| **Flake** | A project with `flake.nix` — reproducible, locked inputs |
| **Home Manager** | Manages user dotfiles/apps declaratively (like NixOS but for `~`) |
| **Module** | A `.nix` file that declares `options` and `config` — composable, no ordering issues |
| **Overlay** | Patches or extends the `pkgs` package set |
| **`pkgs.lib`** | Standard library of Nix helper functions |

## Shell setup

Three shells are configured; Fish is the login shell. To switch default, change `users.users.<name>.shell` in `hosts/nixos/default.nix`.

| Shell | Role |
|-------|------|
| Fish | Default login shell — beginner-friendly, great autocompletions |
| Zsh | Available — run `zsh` to try it |
| Nushell | Available — run `nu` to try it |

## Conventions in this repo

- **Home Manager for user-facing things** — apps, shell, themes, dotfiles.
- **NixOS modules for system things** — services, kernel params, hardware, users/groups.
- **One file per major app** under `home/` — keeps diffs readable.
- **Never hand-edit `hardware-configuration.nix`** — it's generated from the machine.
- **Commit `flake.lock` after every `nix flake update`** so updates are tracked in git.
- **Inline configs via `pkgs.writeText`** only when no proper Home Manager option exists.

## Noctalia desktop shell notes

Noctalia has its own flake — it must be added as a `flake.nix` input and follows nixpkgs-unstable:

```nix
noctalia = {
  url = "github:noctalia-dev/noctalia-shell";
  inputs.nixpkgs.follows = "nixpkgs";
};
```

Its Home Manager module is `inputs.noctalia.homeModules.default`.

Required system services (in `hosts/nixos/default.nix`):
```nix
networking.networkmanager.enable = true;
hardware.bluetooth.enable = true;
services.power-profiles-daemon.enable = true;
services.upower.enable = true;
```

Use the Cachix cache to avoid compiling Quickshell locally (slow):
```nix
nix.settings = {
  extra-substituters = [ "https://noctalia.cachix.org" ];
  extra-trusted-public-keys = [ "noctalia.cachix.org-1:pCOR47nnMEo5thcxNDtzWpOxNFQsBRglJzxWPp3dkU4=" ];
};
```

## Applying config on the VM

1. Clone this repo on the NixOS VM.
2. Copy the machine's generated hardware config into `hosts/nixos/hardware-configuration.nix`.
3. Run `sudo nixos-rebuild switch --flake .#nixos` from the repo root.
